# Cybersecurity Audit – Botium Toys

## Project Overview
This repository contains the deliverables from a simulated internal security audit of Botium Toys, a fictional retail and e-commerce company. The audit was conducted as part of the Google Cybersecurity Certificate program and expanded into a full GRC portfolio project.

## Objective
To assess Botium Toys' current cybersecurity posture, identify critical control gaps, and produce professional audit documentation aligned with industry frameworks.

## Frameworks Used
- PCI DSS (Requirements 3, 4, 7, 8, 12)
- NIST SP 800-53
- NIST SP 800-34
- NIST SP 800-63B
- NIST Cybersecurity Framework

## Deliverables
1. **Internal Audit Findings Report** – Five formal findings written using the Condition/Criteria/Cause/Effect/Recommendation methodology
2. **Remediation Roadmap** – Prioritized corrective action plan with effort levels and timelines
3. **Executive Summary** – High-level summary written for non-technical leadership

## Key Findings
- Absence of encryption for cardholder data (PCI DSS non-compliant)
- Lack of least privilege and access controls in place
- Weak password policy with no centralized password manager
- Lack of disaster recovery plan or data backups
- Lack of intrusion detection system
